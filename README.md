# CS Adventure 🚀

**コンピュータの謎を、体験しながら解き明かす教育コンテンツ**

ブラウザだけで動く、インタラクティブなコンピュータサイエンス入門。
クリックするだけで、キーボードから AI まで仕組みが見えてくる。

🌐 **公開URL**: https://takahashilabo.github.io/cs-adventure/

---

## 特徴

- **環境構築ゼロ** — HTML + CSS + Vanilla JS のみ。サーバー不要
- **触って理解** — スライダー・クリック・アニメーションで直感的に体験
- **明るいポップなデザイン** — 男女問わず親しみやすいパステル + グラデーション UI
- **全章クイズ付き** — 学んだ内容をすぐに確認
- **次のステップ案内** — 各章の完了後におすすめ本・サイト・動画を紹介

## インタラクティブな体験例

- **第1章**: CPUのフェッチ→デコード→実行をステップ実行で追う
- **第2章**: キーボードマトリクスをクリックして行・列走査を可視化
- **第3章**: RGBスライダーで1670万色を体験 / FPSスライダーでアニメの滑らかさを体感
- **第4章**: パケットがネットワーク上を旅するアニメ / TCPハンドシェイクをステップ確認
- **第7章**: Web Audio API でピアノ音を実際に鳴らす
- **第13章**: 重みスライダーでニューロンの出力がリアルタイムに変わる
- **第14章**: 日本語文の Self-Attention ヒートマップをインタラクティブに表示
- **第15章**: 次のトークンをクリックで選んで文章生成を体験 / Temperature で確率分布が変化

## ローカルで開く

サーバー不要。クローンしてブラウザで開くだけ。

```bash
git clone https://github.com/takahashilabo/cs-adventure.git
cd cs-adventure
open index.html   # macOS
# または
start index.html  # Windows
```

## GitHub Pages での公開

1. リポジトリの **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main / (root)**
4. 数分後に `https://takahashilabo.github.io/cs-adventure/` で公開

## 技術スタック

- **HTML5** — セマンティックマークアップ
- **CSS3** — カスタムプロパティ・グラデーション・アニメーション
- **Vanilla JavaScript** — ライブラリ・フレームワーク一切なし
- **Canvas API** — 波形・ネットワーク図・ニューラルネット可視化
- **Web Audio API** — 第7章のピアノ音生成
